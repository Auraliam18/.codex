# ⚡ Aura Trade Panel — داشبورد اتوترید Bitunix

پنل حرفه‌ای معاملات خودکار فیوچرز روی صرافی **Bitunix** با موتور استراتژی نامحدود.
هر استراتژی که فعال کنید، بازار را رصد می‌کند، سیگنال می‌سازد و (در حالت واقعی) مستقیماً روی صرافی ترید می‌کند.

## ✨ امکانات

- **اتصال واقعی به Bitunix Futures** — امضای رسمی OpenAPI (double SHA-256 با هدرهای `api-key`/`nonce`/`timestamp`/`sign`)
- **استراتژی نامحدود** — ۶ استراتژی داخلی + سازنده استراتژی سفارشی از داخل پنل، بدون کدنویسی
  - ★ **Aura Liam Max** — کانفلوئنس ۵ فاکتوره (EMA 21/55 + RSI + MACD + حجم + ATR)
  - ★ **Liam Trader 9** — سیستم امتیازدهی ۹ فاکتوره
  - EMA Cross · RSI Reversal · MACD Trend · Bollinger Breakout
- **دو حالت معاملاتی**: دمو (Paper) کاملاً شبیه‌سازی‌شده با SL/TP و اهرم، و واقعی (Live) با ثبت سفارش MARKET + حد سود/ضرر روی صرافی
- **مدیریت ریسک**: حجم پوزیشن بر اساس درصد ریسک از اکوییتی، سقف پوزیشن باز، cooldown بین سیگنال‌ها، حد ضرر و حد سود مبتنی بر ATR
- **پنل زنده**: نمودار کندل با crosshair و tooltip، فید سیگنال لحظه‌ای، جدول پوزیشن‌ها، تاریخچه معاملات، گزارش رویدادها — همه از طریق WebSocket به‌روز می‌شوند

## 🚀 راه‌اندازی

```bash
pip install -r requirements.txt
python run.py
```

سپس در مرورگر: **http://127.0.0.1:8420**

## 🔑 اتصال به صرافی

1. در Bitunix از بخش **API Management** یک کلید API با دسترسی فیوچرز بسازید.
2. در پنل روی **⚙ تنظیمات** بزنید، API Key و Secret را وارد کنید.
3. با دکمه **🔌 تست اتصال** صحت کلیدها را بررسی کنید.
4. حالت را از «دمو» به «واقعی» تغییر دهید — فقط وقتی که استراتژی را در دمو تست کرده‌اید.

کلیدها فقط به صورت محلی در `data/config.json` ذخیره می‌شوند و هرگز جایی جز `fapi.bitunix.com` ارسال نمی‌شوند.

## 🧩 افزودن استراتژی

**از پنل (بدون کد):** دکمه «＋ استراتژی سفارشی» → شرایط لانگ/شورت را با اندیکاتورها تعریف کنید (RSI، MACD، بولینگر، حجم، EMA).

**با کد:** فایل جدیدی در `app/strategies/` بسازید:

```python
from . import BaseStrategy, Signal, StrategyMeta, register

@register
class MyStrategy(BaseStrategy):
    meta = StrategyMeta(id="my_strategy", name="استراتژی من", description="...")

    def analyze(self, candles):
        # candles: [{"time", "open", "high", "low", "close", "volume"}, ...]
        # return Signal(side="LONG"|"SHORT", price=..., confidence=..., reason=..., sl=..., tp=...)
        return None
```

و در انتهای `app/strategies/__init__.py` ایمپورتش کنید. همین — در پنل ظاهر می‌شود.

## ⚠️ هشدار ریسک

معاملات فیوچرز با اهرم می‌تواند کل سرمایه را نابود کند. این نرم‌افزار «همان‌طور که هست» ارائه می‌شود و هیچ تضمین سودی وجود ندارد. همیشه ابتدا در حالت دمو تست کنید و در حالت واقعی فقط با سرمایه‌ای کار کنید که آمادگی از دست دادنش را دارید.

## 🏗 معماری

```
run.py                  ← اجرای سرور (uvicorn)
app/
  main.py               ← FastAPI: REST + WebSocket + استاتیک
  bitunix.py            ← کلاینت REST بیت‌یونیکس (عمومی + امضاشده)
  engine.py             ← موتور معاملات: حلقه استراتژی‌ها، ریسک، بروکر دمو
  store.py              ← ذخیره تنظیمات و تاریخچه (JSON)
  strategies/           ← فریم‌ورک استراتژی + اندیکاتورها + استراتژی‌ها
static/                 ← پنل وب (HTML/CSS/JS خالص، RTL)
data/                   ← config.json و trades.json (در گیت نیست)
```

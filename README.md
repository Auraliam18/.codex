# ⚡ Liam Trader 9 — پنل اتوترید Bitunix

پنل حرفه‌ای معاملات خودکار فیوچرز روی صرافی **Bitunix** — میزبان استراتژی‌های خودِ شما.
هیچ استراتژی آماده‌ای همراه پنل نیست: استراتژی خودتان را (به‌صورت کد پایتون یا با سازنده بدون کد)
اضافه می‌کنید، واچ‌لیست ارزهایش را می‌چینید، بک‌تست می‌گیرید و بعد موتور را روشن می‌کنید.

## ✨ امکانات

- **اتصال واقعی به Bitunix Futures** — امضای رسمی OpenAPI (double SHA-256 با هدرهای `api-key`/`nonce`/`timestamp`/`sign`)
- **استراتژی نامحدود، متعلق به شما**
  - 🐍 بارگذاری فایل پایتون خودتان از داخل پنل (`data/user_strategies/`)
  - 🧩 سازنده بدون کد با ۳۰ اندیکاتور برتر: RSI، Stochastic، StochRSI، MACD، EMA/SMA، بولینگر، ADX/DI، CCI، MFI، Williams %R، SuperTrend، PSAR، VWAP، ATR، OBV، حجم، مومنتوم
- **واچ‌لیست چندارزی برای هر استراتژی** — تب «ارزها» در کارت هر استراتژی؛ هر تعداد جفت‌ارز که بخواهید رصد و معامله می‌شود
- **بک‌تست داخلی** — تب «بک‌تست» هر استراتژی: بازده، نرخ برد، فاکتور سود، حداکثر افت سرمایه و منحنی اکوییتی روی کندل‌های واقعی صرافی
- **دو حالت معاملاتی**: واقعی (Live، پیش‌فرض) با ثبت سفارش MARKET + حد سود/ضرر روی صرافی، و دمو (Paper) کاملاً شبیه‌سازی‌شده
- **مدیریت ریسک و سرمایه سراسری**: ریسک پیش‌فرض هر معامله، سقف ضرر روزانه با توقف خودکار، سقف پوزیشن‌های باز همزمان، سقف اهرم — به‌علاوه حجم پوزیشن مبتنی بر درصد ریسک، cooldown بین سیگنال‌ها و سقف پوزیشن به ازای هر استراتژی

## 🚀 راه‌اندازی

```bash
pip install -r requirements.txt
python run.py
```

سپس در مرورگر: **http://127.0.0.1:8420**

## 🔑 اتصال به صرافی

1. در Bitunix از بخش **API Management** یک کلید API با دسترسی فیوچرز بسازید.
2. در پنل روی **⚙ تنظیمات اتصال** بزنید، API Key و Secret را وارد کنید.
3. با دکمه **🔌 تست اتصال** صحت کلیدها را بررسی کنید.

کلیدها فقط به صورت محلی در `data/config.json` ذخیره می‌شوند و هرگز جایی جز `fapi.bitunix.com` ارسال نمی‌شوند.
حالت پیش‌فرض «واقعی» است؛ بدون کلید API موتور روشن نمی‌شود و برای تست بدون ریسک می‌توانید حالت را روی «دمو» بگذارید.

## 🧩 قالب استراتژی پایتون

```python
from app.strategies import BaseStrategy, Signal, StrategyMeta, ema, atr

class MyStrategy(BaseStrategy):
    meta = StrategyMeta(id="my_strategy", name="استراتژی من", description="...")

    def analyze(self, candles):
        # candles: [{"time", "open", "high", "low", "close", "volume"}, ...]
        # آخرین کندل = وضعیت فعلی بازار
        # return Signal(side="LONG"|"SHORT", price=..., confidence=0..1,
        #               reason="...", sl=..., tp=...)
        return None
```

همه اندیکاتورهای `app/strategies/__init__.py` (ema، sma، rsi، macd، bollinger، atr، stochastic،
adx، cci، mfi، supertrend، psar، vwap، obv و…) قابل ایمپورت هستند. فایل را از پنل بارگذاری کنید
یا مستقیم در `data/user_strategies/` بگذارید — با ری‌استارت پنل لود می‌شود.

> فایل‌های این پوشه کد پایتون کامل اجرا می‌کنند؛ فقط کدی را بارگذاری کنید که خودتان نوشته‌اید یا به آن اعتماد دارید.

## ⚠️ هشدار ریسک

معاملات فیوچرز با اهرم می‌تواند کل سرمایه را نابود کند. این نرم‌افزار «همان‌طور که هست» ارائه می‌شود و
هیچ تضمین سودی وجود ندارد. استراتژی را اول با بک‌تست و حالت دمو بسنجید و فقط با سرمایه‌ای کار کنید
که آمادگی از دست دادنش را دارید.

## 🏗 معماری

```
run.py                  ← اجرای سرور (uvicorn)
app/
  main.py               ← FastAPI: REST + WebSocket + استاتیک
  bitunix.py            ← کلاینت REST بیت‌یونیکس (عمومی + امضاشده)
  engine.py             ← موتور معاملات: حلقه چندارزی، ریسک سراسری، بروکر دمو
  backtest.py           ← بک‌تستر walk-forward
  store.py              ← ذخیره تنظیمات و تاریخچه (JSON)
  strategies/
    __init__.py         ← فریم‌ورک + کتابخانه اندیکاتورها
    custom.py           ← استراتژی‌های سازنده بدون کد (۳۰ اندیکاتور)
    loader.py           ← لودر استراتژی‌های پایتونی شما
static/                 ← پنل وب (HTML/CSS/JS خالص، RTL)
data/                   ← config.json، trades.json، user_strategies/ (در گیت نیست)
```
